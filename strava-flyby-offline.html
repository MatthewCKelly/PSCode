📡 How to Export Athlete Data from Strava Flyby

Method A — FlybyDirector exportData() ✓ Recommended

The FlybyDirector script (strava-flyby-director.js) has direct access to window.flyby and can export all athlete GPS streams in one command.

1. Open your Flyby URL and wait for athletes to appear on the map.

2. Paste the strava-flyby-director.js script into the DevTools console and press Enter. The director starts automatically.

3. Run this command in the console:

FlybyDirector.exportData()

// Optional: coarser sampling (default is 5 s between points)
FlybyDirector.exportData(10)

// Director doesn't need to be running first -- works any time:
FlybyDirector.stop()
FlybyDirector.exportData(5)

4. A file named flyby-export-*.json will download automatically.

5. Click "Load Athletes JSON" above to load it into this viewer.

If the export logs "0 athletes" — wait for the flyby page to finish loading all athletes, then try again.

Manual JSON Format

    
You can also build the JSON by hand or convert from another source.
    Load it with "Load Athletes JSON".

    
[
  {
    "name": "Alice",
    "startTime": "2024-01-15T08:00:00Z",
    "color": "#fc5200",
    "streams": {
      "latlng": [[51.507, -0.127], [51.508, -0.128]],
      "time":   [0, 5, 10, 15]
    }
  }
]

    
startTime: ISO 8601 string or Unix seconds.
    latlng: array of [lat, lng] pairs.
    time: seconds elapsed from that athlete's activity start.
